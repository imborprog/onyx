# 앱 아이디어 100개 검증 → 최종 1개

조사일: 2026-10-11

## 최종 추천: AI 브랜드 심리테스트 메이커

마케터·소상공인·학원·대행사가 주제만 넣으면 AI가 문항, 결과 유형, 결과 카드까지 10분 안에 만들어 주는 웹 SaaS입니다. 플레이어가 결과를 공유할 때마다 리드 수집과 쿠폰 발급으로 이어집니다.

- 2차 종합 점수 77/100 (2위 외국인 대상 K-사주 67.0, 3위 롤링페이퍼 65.5)
- 사업성 1위, 리스크 1위, 홍보 2위, 자동화 2위로, 네 관점 모두 2위 안에 든 유일한 후보
- 요금(안): 무료(워터마크) / 프로 월 49,000원 / 캠페인 패스 건당 199,000원 / 대행사 월 149,000원
- 월 순이익 500만원 선: 구독 약 140~160곳, 또는 캠페인 패스 월 34건 (추정)
- 중단 기준: 출시 후 6주 안에 무료 제작 300건 미만이거나 유료 B2B 5곳 미만

전체 근거, 90일 계획, 결선 10개 비교, 100개 전체 표는 `report.html`에 있습니다.

## 진행 방법

1. 10개 분야 × 10개로 100개 후보 생성 (`ideas.md`)
2. 서브 에이전트 5개가 아이디어마다 웹 검색으로 경쟁사·수요·지불의사·규제를 확인하고 7개 기준 가중 점수를 매김 (`rubric.md`, `data/ideas_100_scored.json`)
3. 상위 아이디어를 니치 각도로 다듬어 결선 10개 선정 (`shortlist.md`)
4. 리뷰어 에이전트 4개가 사업성 30%, 홍보성 25%, 자동화 25%, 리스크 20%로 교차 심사 (`data/review_*.json`, `data/shortlist_scores.json`)
5. 1위 후보의 핵심 주장을 직접 재검색해 확인
