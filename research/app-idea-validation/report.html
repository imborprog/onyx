01 · 근거

왜 이 아이디어인가

  • 이미 돈이 오가는 시장입니다. 크몽에 심리테스트·MBTI 바이럴 사이트 제작 외주 상품이 여러 개 올라와 있고, 1차 조사 기준 패키지 가격은 39만~159만원입니다. 푸망은 CJ ENM·디즈니·에이블리 등과 브랜드 테스트를 만들어 왔고, W컨셉 협업 테스트는 2주 만에 약 18만 플레이를 기록했다고 보도됐습니다.
  • 중소 사업자용 자리가 비어 있습니다. 푸망은 대형 브랜드 대상 대행형(최소 5만 플레이 보장)이고, 국내 셀프 제작 도구(심테공방, 메타브, 도다툴)는 무료·소비자 중심입니다. AI가 기획까지 대신하고 리드 수집과 쿠폰까지 연결하는 셀프서브 B2B 제품은 이번 조사에서 찾지 못했습니다. 해외에서는 Interact가 월 $27~125 요금으로 이 모델을 검증했습니다.
  • 적은 고객으로 목표에 닿습니다. 월 49,000원 구독이면 약 140~160곳, 캠페인 단건 199,000원이면 월 34건이 월 순이익 500만원 선입니다. 10개 후보 중 필요한 고객 수가 가장 적습니다.
  • 제품이 곧 홍보 채널입니다. 심리테스트는 결과를 공유하는 것이 곧 사용입니다. 무료 플랜 결과 페이지마다 "나도 만들기" 표시가 붙어 테스트 한 건이 수천~수만 번 노출됩니다.
  • 운영이 거의 무인입니다. 테스트 1건의 AI 원가는 수백~1,500원(추정)이고 매출총이익률은 약 82~94%(추정)입니다. 배송·대면 영업·외부 플랫폼 API 의존이 없어 사람 손은 주 2~4시간이면 됩니다.
  • 법적 리스크는 한 번 구현하면 끝나는 유형입니다. 인허가가 필요 없습니다. 개인정보 위탁, 광고 수신동의, 14세 게이트를 제품 기본값으로 넣으면 됩니다. 앱스토어·카카오 정책에 사업 전체가 흔들리지 않는 웹 서비스입니다.
02 · 제품

제품 정의와 4주 MVP 범위

누가 돈을 내나 (우선순위 순)

  • 마케팅 대행사·프리랜서 마케터: 여러 브랜드에 반복해서 써서 이탈이 가장 낮습니다.
  • 학원·교육기관: 신학기·설명회 시즌에 "공부 유형 테스트"로 상담 리드를 모읍니다.
  • 카페·뷰티·필라테스 등 로컬 매장: 결과별 쿠폰으로 방문을 유도합니다.
  • 중소 브랜드·스마트스토어: 프로모션 시즌 이벤트용으로 씁니다.

MVP 기능

  • 주제·브랜드·목표 입력 → AI가 문항 8~12개, 결과 유형 8~16개, 결과 문구 생성 (검증된 테스트 구조 템플릿 위에서)
  • 문구·이미지 편집기
  • 결과 카드 서버 렌더 (한글 폰트로 렌더해 오탈자 없음) + 카카오톡·인스타 공유
  • 리드 수집 폼 (동의 화면·14세 게이트 기본 탑재)
  • 결과별 쿠폰 코드 발급 (CSV 업로드 방식)
  • 성과 대시보드: 플레이, 완주율, 공유, 리드
  • 무료 플랜 워터마크 "Made with · 나도 만들기", 정기결제
03 · 사업성

수익 구조와 손익 계산

무료0원테스트 제작 가능, 워터마크 표시, 리드 수집 없음. 유입용.
프로 구독월 49,000원연간 결제 시 월 39,000원. 워터마크 제거, 리드 수집, 쿠폰, 테스트 무제한.
캠페인 패스건당 199,000원구독 없이 30일 캠페인 1건. 크몽 외주 가격의 절반 이하.
대행사 (제안)월 149,000원브랜드 5개, 화이트라벨. 반복 사용 고객을 묶어 이탈을 줄입니다.
구독 1곳당 월 기여 = 49,000 − 카드수수료 3.5%(1,715) − AI·트래픽 2,000~7,000(추정) ≈ 40,000 ~ 45,300원 고정비(가정) = 인프라 30만 + 마케팅 100만 = 월 130만원 목표 순이익 = 월 500만원 (세금·창업자 인건비 제외) 필요 구독 고객 = 630만 ÷ 40,000~45,300 ≈ 140 ~ 160곳 캠페인 패스만 판다면 = 630만 ÷ 187,000(199,000 − 3.5% − 5,000) ≈ 월 34건 혼합 예시 = 구독 80곳(362만) + 캠페인 15건(281만) − 고정비 130만 ≈ 513만원
사업성 심사에서 지적한 약점 브랜드는 캠페인 단위로 1년에 1~3회 쓰기 때문에 월 구독 이탈이 높을 수 있습니다(월 8~15% 추정). 그래서 연간 결제 할인, 캠페인 패스, 대행사 플랜을 처음부터 섞습니다. 해외 1위 Interact도 ARR $1M까지 7년이 걸렸으므로 한국 B2B 시장의 상한은 수백 곳 규모로 보고 계획합니다.
04 · 홍보성

홍보 전략

제품이 고객을 데려오는 순서

  1. 사업자가 무료로 테스트를 만들어 배포합니다.
  2. 소비자가 플레이하고 결과 카드를 카카오톡·인스타 스토리에 공유합니다.
  3. 결과 페이지 하단의 "Made with · 나도 만들기"를 일부가 누릅니다.
  4. 친구용 테스트를 만드는 개인 제작자가 늘면서 공개 갤러리와 검색 노출이 쌓입니다.
  5. 제작자 중 로고를 올리거나 쿠폰 기능을 눌러 본 사업자에게 유료 체험을 자동으로 보냅니다.

핵심 채널 3개

  • 제품 내장 바이럴: 워터마크, 나도 만들기 버튼, 공개 테스트 갤러리
  • 검색 노출(SEO): 공개 테스트마다 검색용 페이지를 만들고, "심리테스트 만들기"·"이벤트 아이디어" 주제로 네이버 블로그 운영
  • 마케터 커뮤니티: 아이보스, 디스콰이엇, 마케터 오픈채팅, 스레드·인스타 릴스

첫 100개 고객 확보

  • 출시 전 4주 동안 직접 만든 트렌드 테스트 30개를 스레드·인스타·에브리타임에 배포해 플레이 수와 사례를 쌓습니다.
  • 학원·카페·뷰티샵 30곳에 "브랜드 테스트 무료 제작 + 쿠폰 연동"을 제안하고 결과 수치를 사례로 공개합니다.
  • "크몽 외주 39만원 대신 AI로 10분" 비교 콘텐츠를 마케터 커뮤니티에 올립니다.
  • 크몽에 이 도구로 만드는 "제작 대행" 상품을 등록해 초기 현금과 사례를 동시에 확보합니다.

마케팅 콘텐츠 자동화 수준은 매우 높습니다. 창업자가 AI로 시즌·트렌드 테스트를 주 5~10개 만들어 자체 채널로 돌리면, 트래픽과 사례와 검색 노출이 한 번에 쌓입니다. 바이럴 노출 대부분이 소비자에게 가므로, 유료 전환은 2단계 퍼널(무료 제작자 → 사업자 유료)로 설계해야 합니다.

05 · 자동화

자동화 설계

기술 구성 (MVP 3~4주)

  • Next.js(Vercel) + Supabase (테스트·응답·리드 테이블, 브랜드별 데이터 격리)
  • LLM 구조화 출력으로 문항·결과 생성. 유료는 상위 모델, 무료는 경량 모델
  • 결과 카드는 서버에서 폰트로 렌더(@vercel/og)
  • 카카오 공유 SDK, 토스페이먼츠·포트원 정기결제, 세금계산서 API

자동 vs 수작업

  • 자동: 테스트 생성, 결과 카드, 공유 루프, 리드 수집·내보내기, 쿠폰 발급, 결제·갱신, 사용량 리포트 메일, FAQ 챗봇 고객응대
  • 수작업 (주 2~4시간 추정): 초기 고객 데모와 맞춤 요청, 큰 고객 견적, 부적절한 테스트 검토
  • 원가: 테스트 1건 AI 원가 수백~1,500원(일러스트 포함 시), 무료 사용자는 건당 수 원 수준(추정)
06 · 리스크

리스크와 대응

리스크대응
캠페인 한 번 쓰고 구독 해지연간 결제 할인, 캠페인 패스, 대행사 플랜. 시즌 캘린더(신학기·추석·연말) 알림으로 재사용 유도
AI가 만든 테스트가 밋밋해 공유가 안 됨검증된 구조 템플릿(축 2~4개, 유형 8~16개) 위에서 생성. 잘 퍼진 테스트 패턴을 라이브러리로 축적
마케터가 AI 앱 빌더로 직접 만들어 버림제작보다 운영 기능으로 차별화: 결과 카드 바이럴, 쿠폰, 리드 관리, 성과 대시보드
리드 데이터 유출·법적 책임 (개인정보보호법 수탁자)위탁 계약서 템플릿, 동의 화면 기본값, 14세 미만 차단, 보관기간 자동 파기, 브랜드별 데이터 격리
쿠폰·이벤트 안내 발송 (정보통신망법 광고성 정보)수신동의 분리, "(광고)" 표기, 야간 발송 별도 동의. MVP는 링크·코드 방식으로 시작

07 · 실행

90일 실행 계획

1~2주차개발 전 수요 검증. 랜딩페이지와 대기자 명단을 열고, 직접 만든 트렌드 테스트 10개를 배포합니다. 크몽에 심리테스트 제작 상품을 올려 실제 주문 문의가 오는지 봅니다. 로컬 매장·학원 30곳에 무료 파일럿을 제안합니다.
3~6주차MVP 개발. 생성·편집·결과 카드·공유·리드·쿠폰·결제·대시보드를 만들고 파일럿 5~10곳에서 실제로 운영합니다.
7주차공개 출시. 파일럿 수치(플레이 수, 리드 수)를 사례로 공개하고, 마케터 커뮤니티에 출시 글과 크몽 외주 비교 콘텐츠를 올립니다.
8~12주차성장. 시즌 테스트를 주 5~10개 공개 갤러리에 올리고, 무료→유료 전환 메일을 자동화하고, 대행사 10곳에 대행사 플랜을 제안합니다. 12주차 말(출시 후 6주)에 중단 기준을 점검합니다.

매주 볼 지표: 무료 테스트 제작 수, 테스트당 평균 플레이, 워터마크 클릭→가입률, 무료→유료 전환율, 월 이탈률, 월 반복 매출(MRR).

09 · 방법

검증 방법

  1. 100개 후보 생성. AI 생산성, 소상공인 B2B, 크리에이터, 교육, 건강, 금융, 라이프스타일, 육아·반려동물, 소셜·엔터, 유틸리티 10개 분야에서 10개씩 뽑았습니다.
